# Auto Google Flow đã ngừng sử dụng

Theo yêu cầu chủ repo ngày 05/11/2026, mã điều khiển Flow, extension và CLI liên quan đã gỡ. Tạo ảnh bên ngoài, lưu vào hinh/ theo ID canh-001.png hoặc 001.png, chạy `python run.py run <project> --only collect` để kiểm tệp cục bộ.

Profile và hồ sơ submit cũ được giữ để đối chiếu. Báo cáo Flow trước ngày này là lịch sử, không mô tả chức năng hiện hành.
